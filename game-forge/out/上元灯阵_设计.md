# 设计方案 — 上元灯阵

类型: 合成+塔防 | 一句话: 上元灯会题材，摇签抽灯兵、合灯升阶、守主灯灯阵，每日换图+异步榜

## 核心循环
```
摇签消耗灯珠(第n次=10×1.35^n)→随机得灯兵/灯灵将/灯铲(扩格)→同类同级合成升阶(ATK×1.4、FRQ×1.1，5级封顶)→拖入有限格子部署→12波灯灵来袭守5命主灯→胜利掉落灯芯与金币→局外道具店(主动2槽)+每日异步对抗+段位榜
```

## 机制
- 抽卡式征兵盲盒
- 空间管理(有限格子+随机铲子扩张)
- 武将字牌碎片解锁全屏技能
- 非对称数值惩罚(掉级×0.9^n)
- 每日4图轮换+buff当日失效
- 异步对抗(回放对手昨日操作)

## 数值设计

- **灯珠消耗**: "10×1.35^n"
- **灯种POW配平**: "100±3 (走马灯近战高伤/河灯远程慢/孔明灯群攻/纱灯快攻低伤)"
- **合成升阶**: "ATK×1.4 FRQ×1.1 5级封顶"
- **掉级惩罚**: "×0.9^n"
- **波次**: "12波，BOSS每4波"
- **主灯命条**: "5"
- **武器回收**: "三阶以下卖金币，回收价=购入×0.6"
- **道具池**: "每日12随机8，主动限2槽"

## 美工风格

- 风格: 国风水墨灯彩 (水墨+灯彩极简，发光字牌，程序化动效)
- 配色: 墨色+暖黄灯光 ['#1a1a2e', '#f5e8c8', '#e8a030', '#8a2020', '#d8c8a8']
- 情绪: 宁静、节庆、东方禅意
- 参考: ['赵云与阿斗(汉字水墨)', '上元灯阵']
