# 设计方案 — 玉匣开鉴

类型: 赌石收集 | 一句话: 轻松拿捏了式赌石玩法，切玉得宝，赌性+收集双驱动，每日开匣

## 核心循环
```
每日3匣(铜钱免费3+广告+1+成就攒)→切玉(随机剖面5属性:皮壳/裂/砂/雾/种)→显示玉质→再切或出→出宝(白→传说5阶)→鉴宝阁图鉴+行商汇率(±20%浮动)
```

## 机制
- 随机玉饼剖面(种/水/色/净权重40/25/20/15%)
- 三维评分出宝(玉质+皮壳+完整性)
- 全服限量金(每日金≤200件按顺序分配)
- 行商每日汇率±20%(再等等博弈)
- 满图鉴解锁新匣池

## 参考游戏: 赌石潮(轻松拿捏了)
借鉴: 随机剖面+稀缺判定+每日重置的爆款周期 + 行商汇率'再等等'博弈 + 限量金FOMO

## 数值设计

- **出宝概率**: "白55/青25/绿13/紫6/金0.8%"
- **玉质评分**: "种40%+水25%+色20%+净15%(可热调)"
- **铜钱**: "每日3+广告+1"
- **行商汇率**: "每日±20%"
- **限量金**: "每日≤200件"

## 美工风格

- 风格: 像素鉴宝剖面 (像素/简笔双线，程序化噪声剖面)
- 配色: 青玉绿+玄石灰+金 ['#2a4a3a', '#7ec8a0', '#3a3a3a', '#f5d860', '#8a7a6a']
- 情绪: 赌性、稀缺、收藏
- 参考: ['赌石潮(轻松拿捏了)']

## 风险

- 赌性需控制每日重置节奏避免挫败
