# 设计方案 — 百工图鉴

类型: 合成+经营 | 一句话: 大宋百工题材，收集匠人字牌合成升级工坊，自动接单赚钱，离线收益驱动回流

## 核心循环
```
接单(随时间刷新, 消耗材料产出银两)→收集匠人字牌二合一升阶(白→金, 概率60/45/32/20/8%)→工坊每3级解锁新订单池→每日限定珍品订单→赛季官印积分
```

## 机制
- 随机接单+材料缺口
- 同类字牌合成升阶
- 高阶工坊生产×1.5/阶
- 订单稀有度70/20/8/2%(普/珍/绝/传说)
- 离线收益12h封顶(广告翻倍/延至24h)
- 赛季30天官印排行(TOP10%限定皮肤+徽章)

## 参考游戏: 寻道大千
借鉴: 挂机收益指数增长制造在线压力 + 多资源线互锁(灵兽需洗练/精怪需升级) + 增减伤属性为付费锚点

- **订单报酬**: "基础×1.08^等级"
- **材料消耗**: "×1.12^等级(缺口靠抽卡/广告)"

- **字牌概率**: "白60/青45/绿32/紫20/金8%"
- **赛季**: "30天换朝代(宋→元→明→清)，旧官印转下赛季"
