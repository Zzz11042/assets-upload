# 设计方案 — 墨剑江湖

类型: 文字肉鸽割草 | 一句话: 向僵尸开炮割草肉鸽压到水墨文字层：一横一竖一撇就是剑气，波次割草+build随机

## 核心循环
```
波次割草(每30s一波墨点成潮)→主角自动挥笔清怪→玩家2件事:选招式方向(上下左右横扫)+攒墨量放全屏大招→波后3选1词缀(36张池)→掉落残页合成武功(武学树9系)→每10波墨蛟BOSS
```

## 机制
- 低操作割草(自动挥笔)
- 局内build随机(36词缀, 稀有度60/25/10/4/1%)
- 波次怪物血=基础×1.15^波
- 词缀期望DPS提升≈1.3倍/波(build成长>怪物成长)
- 武学树9系每级+2%基础属性(100级封顶)
- 墨蛟BOSS(墨点变形需换招式破盾)

## 参考游戏: 向僵尸开炮
借鉴: 低操作门槛割草 + 局内build随机多巴胺 + 局外成长缓慢保证微氪生存 + 2D射击手感节奏

## 数值设计

- **怪物血**: "基础×1.15^波"
- **词缀DPS**: "≈1.3倍/波"
- **词缀稀有度**: "60/25/10/4/1%"
- **武学树**: "9系每级+2%, 100级"
- **单局**: "3分钟"

## 美工风格

- 风格: 水墨武侠笔触 (程序化笔触剑气，墨点敌人越打越浓)
- 配色: 浓淡墨色+朱砂印 ['#0a0a0a', '#4a4a4a', '#8a8a8a', '#c8c8c8', '#c84040']
- 情绪: 侠气、爽感、禅意
