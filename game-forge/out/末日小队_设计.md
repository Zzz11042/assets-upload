# 设计方案 — 末日小队

类型: 即时战术+经营 | 一句话: 末日废墟里指挥小部队接任务打怪，带资源回营地经营建设制作装备，推更深地块揭开病毒阴谋

## 核心循环
```
出击任务(战斗/探索)→带资源回营地→经营建设/制作/治疗→部队营地变强→推更深任务→剧情事件→更强资源
```

## 机制
- 俯瞰2.5D指挥小队(3-6士兵+指挥官)
- 点取移动+点取自动攻击+特殊武器拖动瞄准
- 兵种克制(步兵扛线/机枪输出/狙击爆头/榴弹AOE/医疗/工兵)
- 营地6建筑(兵营/工坊/厨房/医疗/围墙/电台)
- 双层生存数值(食物/士气/伤病)
- 制作系统(零件→武器改装/食物烹饪/药品合成)
- 章节制叙事(4章每章5-8任务)
- 任务星评(全灭无伤/限时/收集)

## 参考游戏: 末日小队(自研)
借鉴: 小小部队战术射击 × 阿瑞斯病毒生存经营 + 双层生存数值(食物/士气/伤病) + 章节制叙事

## 数值设计

- **单局**: "10-20分钟"
- **士兵状态**: "饥饿/疲劳/伤病/士气(带伤上阵debuff)"
- **首章**: "2-3小时通关"
- **性能**: "单屏≤30单位30fps"

## 美工风格

- 风格: Q版微缩军事 (轻度3D卡通军事(Q版迷你兵种+载具))
- 配色: 军绿+沙土+金属 ['#4a5a3a', '#8a7a5a', '#3a3a3a', '#6a8a4a', '#c8b890']
- 情绪: 紧张、末世、萌化
- 参考: ['Tiny Troopers 2', '末日小队']
