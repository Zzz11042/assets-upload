# 第80章

雨夜，林远独自坐在南方枢纽市一栋旧公寓的顶楼，窗帘缝隙里漏进一盏探照灯的白光，扫过满桌散落的图纸——那是"静默之网"的地面节点分布图。三年前，边陲城的数据中心被毁，他亲眼看着自己的母亲在火灾现场倒下，从那以后，"奇点"密钥就藏在她的遗物里，辗转落入沈默手中，如今又回到了自己手里。

桌上的玉扣是他母亲留给他的最后一样东西。温润，冰凉，边缘磨得发亮，是那种老式高维数据锚点的物理外壳，内部却早已空了。

"第三把钥匙"，沈默在八十六章留下的最后一句话在他耳边回荡。

"你不是在找钥匙，你是在找自己。"

林远的手指停在那枚玉扣上，停了三秒。然后他拨通了沈默的加密频道。

"信号-7。"他说，"沈默，'静默之网'的高维连接还没断，我在城南地下机房看到他们的中继节点还亮着红灯。三小时前，'萤火'派系的人出现在机房外围，他们不是来关机的，是来换锁的。"

电话那头沉默了整整五秒。

然后沈默的声音冷得像冰面下的暗流："你确定？"

"我确定。"

"别来。"沈默说，"那里是诱饵。'铁幕'的人已经在巷口布好了。你只是棋子。"

林远盯着那枚玉扣，忽然笑了。笑容里没有温度，只有一种近乎狂热的兴奋。

"棋子又怎样。"他说，"我见过高维算力模型里所有可能被优化的路径，但我没算过——我这条路径，你们算不出来。"

他站起身，把玉扣揣进内袋，指尖划过金属扣面的那一刻，他感知到一股微弱的脉冲从玉扣内部传出，像是某种沉睡了很久的东西正在被唤醒。

窗外，雨声更大了。巷口，三辆黑色轿车无声地滑入阴影，车灯熄灭。

林远没有回头。他推开公寓的门，走进雨里，帽檐压低，步伐不快不慢。

"游戏开始了。"他低声说，声音被雨吞没。
