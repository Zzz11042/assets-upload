# 第79章  寂静中的回响

夜色如墨，浓稠得化不开，将整座庄园死死笼罩在一片令人窒息的黑暗之中。风停了，连平日里总在廊柱上盘旋鸣叫的秋蝉也仿佛被按住了嘴，四周静得只剩下雨水顺着屋檐滴落的“滴答”声，每一下都像是敲在人心尖上的鼓点。

林远站在二楼的落地窗前，指尖无意识地摩挲着冰冷的玻璃。他的目光穿过雨幕，落在楼下那个被探照灯惨白光晕笼罩的庭院里。那里，停着一辆黑色的轿车，车灯早已熄灭，只剩后窗上贴着的反光贴纸，在黑暗中像是一只半睁的盲眼，透着诡异。他的胸口像压了一块巨石，呼吸变得急促而沉重。脑海中不断回放着刚才在那个地下室里看到的一切：那面墙上密密麻麻排列的照片，每一张都是他曾经以为已经“处理干净”的受害者，而最后一张，却是他的双胞胎哥哥——那个本应在三年前车祸中失踪的人。

“你看见了什么？”

一道沙哑的声音在身后响起，惊得林远浑身一颤。他猛地转身，看见那个一直沉默寡言的管家老陈正站在走廊尽头。老人的身形佝偻，手里拄着一根黑色的手杖，脸上的皱纹在昏暗的灯光下显得沟壑纵横，眼神浑浊却深邃，仿佛两口深不见底的枯井，静静地看着他。

林远强压下想要拔枪的冲动，努力让自己的声音听起来平稳：“老陈，我知道你都看到了。”

管家缓缓走近，每一步都踩在实木地板上，发出沉闷的声响，像是在丈量着两人之间的距离，也像是在丈量着生与死的界限。他在林远面前三米处停下，微微俯身，苍老的面容上看不出任何情绪波动，只有那双眼睛，在那一瞬间闪过一丝难以察觉的悲悯。

“少爷，”老陈低声唤道，这声称呼在此刻显得异常沉重，“有些秘密，就像这宅子下面的地基，一旦挖开，上面的一切都会崩塌。你哥哥……他还活着，但这并不意味着他是好人，也不意味着你是无辜的。”

“我知道他在哪。”林远盯着老人的眼睛，心中涌起一股难以言喻的复杂情绪，既有看到亲人存活的狂喜，更多的是对真相即将被揭开的恐惧。“但我更想知道，你们到底在策划什么？那些照片，那些尸体，还有他为什么留在那里？”

老陈没有回答，只是从宽大的中山装口袋里掏出一个陈旧的铁盒，缓缓放在脚边的地板上。铁盒发出“哒”的一声轻响，在寂静的走廊里显得格外刺耳。林远没有动，眼神紧紧锁定在那个铁盒上。老陈直起腰，转身向黑暗深处走去，背对着他挥了挥手，仿佛赶走一只不受欢迎的苍蝇。

“钥匙在盒子里，答案在里面。但记住，少爷，门一旦打开，你就再也回不来了。”

脚步声消失在走廊尽头，留下林远独自面对那个冰冷的铁盒。他深吸一口气，弯腰捡起铁盒。盒子比想象中要轻，里面似乎并没有装什么东西沉甸甸的重量，但那种未知的恐惧感却让他指尖发抖。他打开铁盒，里面躺着一把生锈的黄铜钥匙，还有一张泛黄的黑白照片。照片上，年轻的父亲和两个一模一样的小男孩站在老宅的门前，笑容灿烂，背景里阳光明媚，与现在的阴冷形成残酷的对比。照片背面，用钢笔写着一行歪歪扭扭的小字：“别相信血缘，只相信利益。”

林远感到一阵眩晕。血液仿佛在血管里倒流，心脏剧烈地撞击着胸腔。他抓起钥匙，不顾老陈的警告，冲向了地下室。通往地下的楼梯陡峭且狭长，墙皮剥落，露出里面斑驳的红砖，空气中弥漫着一股陈年霉味和淡淡的铁锈味。每下一级台阶，他心中的疑云就浓一分。

来到地下室最深处的那扇铁门前，林远将钥匙插入锁孔。锁具老旧，转动时发出刺耳的摩擦声。随着“咔哒”一声轻响，厚重的铁门缓缓开启，一股潮湿而冰冷的气息扑面而来。门后并不是他想象中的陷阱或刑房，而是一个宽敞的储藏室，里面堆满了落满灰尘的纸箱和文件袋。

在房间的中央，一张书桌孤零零地摆在那里。桌上放着一台老式的收音机，屏幕漆黑，但在这一刻，收音机竟然“滋啦”一声亮了。刺耳的白噪音过后，一个经过变声器处理的声音从里面传出来，听起来像是电流混合着人声，令人毛骨悚然。

“林远，你终于来了。”

熟悉的声音穿透了变声器的伪装，那是他的父亲。那个在家族中拥有绝对权威、看似慈祥实则冷血无情的男人。林远猛地抬头，四下张望，试图找到声音的来源，但除了那张书桌和那些堆积如山的文件，空无一人。

“你知道你在做什么吗？”收音机里的声音平静得可怕，带着一种居高临下的审视，“你以为你在追寻正义？不，你只是在拆解你的父亲为你精心打造的迷宫。你哥哥林风，他不是受害者，他是叛徒。他偷走了我们要卖给海外买家的核心代码，他逃走了，但他也带走了家族的耻辱。”

林远冲到桌前，抓起那些文件袋。里面是一摞摞的合同、账本，还有大量的转账记录。他的目光快速扫过，指尖划过一个个冰冷的数字和签名，冷汗浸湿了后背。原来，所谓的失踪，不过是一场精心策划的清洗。而他，一直被蒙在鼓里，成为了这段关系中最完美的替罪羊，或者是下一个被牺牲的棋子。

“我哥哥现在在哪里？”他对着收音机吼道，声音因愤怒而扭曲。

“他在那里。”收音机里的声音指向桌子下方，“就在地板下面。如果你想知道他是怎么死的，或者怎么‘活’着，自己挖开看看。”

林远跪在书桌前，颤抖着手拉开了桌下的一块暗板。里面是一个金属保险箱，上面贴着一张便签，上面只有他的父亲亲笔写的两个字：“自首”。

就在此时，地下室的铁门从外面被猛地撞开，强光手电的光芒刺破了黑暗，几道黑影涌入。林远知道，时间到了。他紧紧握住那张铁钥匙和照片，眼神中最后的一丝犹豫消散，取而代之的是一种决绝的寒光。无论结局如何，真相已经掌握在他手中，而这一次，轮到他来书写终局。
