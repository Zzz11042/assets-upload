# 终极对决

暮色如血，将废弃的旧码头染成一片暗红。海风裹挟着腥咸的水汽，猛烈地拍打着生锈的铁栏杆，发出令人牙酸的吱嘎声。林远站在一艘搁浅的货船甲板上，手中的合金短刀在昏暗的天光下折射出冷冽的寒芒。他的呼吸已经有些急促，汗水顺着额角滑落，滴落在斑驳的混凝土甲板上，瞬间被风干成深色的斑点。对面的赵坤站在船尾的阴影里，黑风衣的下摆随风翻飞，像是一团凝聚的黑色风暴。赵坤手里把玩着一枚冰冷的硬币，指节因用力而泛白，那双鹰隼般的眼睛里没有半分怜悯，只有捕猎者即将吞噬猎物时的亢奋与残忍。

“林远，你累了。”赵坤的声音低沉沙哑，带着一丝戏谑，“刚才在仓库里逃出来，你的肋骨应该断了两根吧？还要坚持多久？不如跪下，我会让你死得痛快点。”

林远没有说话，只是缓缓调整了站姿，左腿微曲以支撑右膝的旧伤，右手持刀，刀尖斜指地面，形成防御与进攻兼备的低姿。他在心里飞速回顾着赵坤刚才的攻击轨迹：左拳试探，右腿重踢，中间夹杂着一次极具欺骗性的假动作。赵坤不仅力量惊人，而且身手经过专业训练，更可怕的是他对林远习惯的精准预判。常规的力量对抗，林远必输无疑。唯有智取，唯有在对方最自信的瞬间，撕开那层坚不可摧的铠甲。

突然，赵坤动了。没有预兆，黑风衣如同鬼魅般瞬间欺近，速度之快甚至在空气中拉出了一道残影。林远瞳孔猛地收缩，身体本能地向后仰去，堪堪避过那记带着毁灭性力量的肘击。巨大的冲击力让身后的铁栏杆剧烈变形，发出刺耳的金属扭曲声。林远没有趁机反击，而是借着后仰的惯性，右脚重重蹬地，身体横向滑动，像是一条敏捷的游鱼，瞬间绕到了赵坤的侧后方。

“太慢了。”赵坤冷笑一声，甚至没有回头，右手反手一挥，短棍带着风声扫向林远的后颈。林远险之又险地翻滚躲过，背部擦着甲板滑出数米，激起一片灰尘。他迅速起身，利用甲板上的杂物作为掩护，拉开距离。此时，海风突然转大，远处的灯塔发出有节奏的闪烁，将两人的影子拉得细长而扭曲。

“别躲了，林远。”赵坤停下脚步，眼神中闪过一丝不耐烦，“你藏得了初一，藏不了十五。幕后那位先生只想要结果，过程并不重要。”

“幕后？你们到底是谁的人？”林远单膝跪地，调整着呼吸，手中的短刀指向虚空，似乎在寻找破绽。

赵坤没有回答，反而再次发起进攻。这一次，他的招式更加凌厉，棍影如织，密不透风。林远只能被动防御，格挡、闪避，每一次接触都让他感到臂膀的麻木。赵坤的力量像大山一样压迫过来，林远意识到，如果一直被动挨打，不出三分钟，自己就会像之前处理那些叛徒一样，变成一具冰冷的尸体。

突然，林远的眼神变了。他在赵坤一次高举短棍准备下劈的瞬间，并没有后退，反而猛地向前踏出半步，撞入赵坤的中距离。这是赵坤最讨厌的距离，但也是他判断力最容易混乱的时刻。林远左臂硬扛短棍的横扫，剧痛钻心，但他咬紧牙关，右手的短刀不再防御，而是如毒蛇吐信般，直刺赵坤肋下旧伤的位置——那是赵坤在三个月前与另一伙势力火拼时留下的隐患，虽然赵坤极力掩饰，但林远早已从缴获的文件中得知情报。

赵坤吃痛，眼神中第一次露出了慌乱，但多年的格斗经验让他瞬间反应过来，左手成掌，狠狠拍在林远的胸口。林远倒飞出去，撞在一堆集装箱上，咳出一口鲜血。他挣扎着想要起身，却发现肋骨断裂处传来撕裂般的疼痛，视野模糊了一瞬。

“就这点本事？”赵坤缓步走来，居高临下地看着林远，短棍在地面轻轻敲击，“哒、哒、哒”，宛如死神的倒计时。

林远靠在集装箱的阴影里，嘴角溢出一丝血迹，却突然笑了。那笑容里带着一种令人心悸的冷静：“赵坤，你以为你赢了？看看你的左手。”

赵坤下意识地低头，瞳孔骤缩。在他的左臂衣袖下，不知何时多出了一个微型通讯器，红色的信号灯正在疯狂闪烁。就在刚才林远近身搏斗的混乱中，他利用短刀的锋芒，不仅刺伤了赵坤，更划开了通讯器的外壳，并激活了内置的紧急定位模块。那个模块会直接连上赵坤身后那个神秘组织的主控终端。

“你……”赵坤的脸色瞬间变得惨白，原本冷酷的面具彻底碎裂。他疯狂地试图拆卸那个通讯器，但林远的动作比他更快。林远不知从哪里掏出一枚信号干扰器，狠狠拍在赵坤的胸口。强烈的电磁脉冲瞬间瘫痪了通讯器，也干扰了赵坤体内植入的生物芯片。

赵坤发出痛苦的嘶吼，身体剧烈抽搐，单膝跪地。他眼中的疯狂愈发浓烈，死死盯着林远，嘴角扯出一个扭曲的笑容：“你以为这样就能赢？就算你杀了我，也没用……‘清道夫’计划已经启动，那个名单上的名字……一个都跑不掉……你以为你在对抗我，其实你只是在棋盘上一颗无关紧要的棋子……”

“说，幕后黑手到底是谁？”林远拔出短刀，一步步逼近，刀尖抵在赵坤的咽喉。

赵坤剧烈地喘息着，眼神中最后的一丝清明逐渐涣散，却在此时露出了一个诡异的、近乎解脱的微笑。他看着林远，声音微弱却异常清晰：“去查查……旧港区的‘圣殿’……还有，那位从不露面……只用数字编号的……‘零号’……”

话音未落，赵坤的头缓缓垂下，失去了生机。海风再次呼啸，吹散了甲板上的血迹。林远站在尸体旁，手握短刀，指节发白。他知道，真正的战争才刚刚开始。那个“零号”，那个“圣殿”，以及那份未知的名单，如同巨大的阴影笼罩在城市的上空，比眼前的赵坤更加可怕。他深吸一口气，眼神从悲痛转为冰冷的决绝，转身走向码头尽头的小径，消失在茫茫夜色之中。这场对决只是序幕，通往真相的路，注定布满荆棘。
