# 第78章

窗外的风带着初夏特有的潮湿气味，透过未完全拉严的窗帘缝隙，隐隐探入屋内，将桌角那张泛黄的信纸吹得微微颤抖。屋内没有开灯，只有电脑屏幕散发着幽冷的蓝光，映照在林远满是红血丝的眼底。他死死盯着屏幕上那行刺眼的红色警告：“数据链断裂，核心代码丢失”，指节因为过度用力而泛白，骨节咔咔作响。

这不仅仅是一次服务器故障。

“老板，警察那边来了三个电话，都打到了前台。”助理小林在门外小心翼翼地点了点头，声音压得极低，仿佛怕惊动了什么沉睡的巨兽，“还有一家媒体的问询，问咱们是不是要跑路了。”

林远没有回头，只是烦躁地扯了扯领口，那根紧绷的领带像一条绞索，让他感到窒息。他站起身，高大的身影在昏暗的房间里投下一道压抑的剪影。他走到落地窗前，推开窗户。城市的夜景在脚下铺开，霓虹闪烁，车流如织，每一个光点都像是无数个秘密在流动。他点燃了一根烟，深吸了一口，辛辣的烟雾在黑暗中缓缓晕开。

“小林，去查一下黑金资本最近的资金流向。”林远的声音冷冽，像是冰面下的暗流，“还有，联系陈叔，让他那边的人盯紧东区的地下交易所。今晚，如果我还见不到那份完整的备份，我就自己去见见那几个老家伙。”

小林咽了口唾沫，低声说道：“可是，老板，您已经三天没睡了。昨晚在会议室，张总和赵总吵得不可开交，最后直接摔了杯子走人。现在董事会内部……四分五裂，人心浮动啊。”

林远吐出一个烟圈，看着它上升、扭曲、消散，眼神却依旧清明得可怕。“人心浮动？那就让他们跳。跳得越高，摔得越重。”他转过身，嘴角勾起一抹孤绝的弧度，那笑容里没有丝毫温度，“传令下去，冻结所有高管的个人账户。谁要是敢在这节骨眼上抛售股份，直接送进局子。”

小林打了个寒颤，默默退出了房间。门轻轻合上的那一刻，林远独自站在空旷的办公室中央。四周死寂，只有他自己沉重的心跳声，在胸腔里一下一下地撞击着，仿佛某种倒计时即将终结。

他摸出手机，屏幕上亮着一条新来的未接来电。备注名只有两个字：苏婉。那是他的前妻，也是这场风暴背后最隐秘的推手。

林远的手指悬停在通话键上方，指尖微微颤抖。这一瞬间，他的脑海中闪过了太多碎片：三年前那场暴雨中的婚礼，她穿着洁白婚纱在雨中等待他迟到的场景；离婚协议书上那行刺目的“自愿解除婚姻关系”；以及昨天深夜，她发来那张只有背景图、却让人心惊肉跳的监控截图——那张截图里，他信任的财务总监，正拿着装有核心算法的U盘，走向黑金资本的车。

“嘟——嘟——”

电话响了第三声。林远的眼神冷了下来，拇指按下接听。

“江总，这么晚，没休息吧？”电话那头，苏婉的声音轻柔得像是一杯温热的奶，却让林远浑身的血液瞬间凝固。这种温柔的语调，往往意味着杀戮的前奏。

“苏婉，我没时间听废话。”林远掐灭了烟，烟雾散去，露出他冷硬的下巴。

“怎么，是忙着销毁证据，还是忙着准备跳楼？”苏婉轻笑了一声，那笑声在空旷的办公室里回荡，令人毛骨悚然，“我听说，黑金那边很急。他们的董事局今晚八点钟要开会，如果你不能在八点前把干净的数据交出来，他们就会启动B计划。你知道B计划是什么吧？”

林远闭上了眼睛，深吸了一口气。B计划。那不是商业并购，那是工业间谍罪，是足以让江氏集团万劫不复的刑事指控。黑金资本的背后，站着的是本市最有权势的沈家。

“我为什么要怕你们？”林远反问，声音平静得可怕。

“因为你没得选。”苏婉的声音突然冷了下来，不再有任何伪装，“你的备份服务器在东区的机房，对吗？那里没有你的权限，只有我知道备用钥匙的位置。林远，把公司交出来，我可以让这件事像个意外事故一样结束。否则……”

否则，你会死。

这句话苏婉没说出口，但林远听得懂。在这座城市的地下规则里，死亡往往不来自枪口，而来自一张白纸黑字的举报信，或者一个精心设计的“意外”。

林远睁开眼，眼神中最后一丝温和褪去，取而代之的是一片冰冷的刀锋。“苏婉，你算错了一件事。”

“哦？”

“你以为备份在东区的机房？那只是诱饵。真正的核心，我已经把它加密拆分成了八段，分散在市里的八个不同云节点。只要我活着，任何一个节点丢失，你们拼出来的就是一堆乱码。”林远站起身，整理了一下西装领口，声音如磐石般坚不可摧，“除非，我亲手交给你。而我现在不想。”

“好……很好。”电话那头传来苏婉危险的喘息，她似乎被激怒了，“林远，你这是在宣战。记住，今晚过后，这座城里就没有你的位置了。”

“那就试试看。”

挂断电话，手机屏幕暗了下去。屋里再次陷入死寂。林远看了一眼墙上的挂钟，指针正飞速逼近午夜十二点。距离苏婉说的“最后期限”，还有八个小时。

他抓起外套，快步走向电梯。在电梯门关闭的瞬间，他看到了镜子里的自己：脸色苍白，眼窝深陷，但那双眼睛却亮得惊人，像是一头被逼到悬崖边缘、准备绝地反击的困兽。

门开了。

大厅里空无一人，只有前台的小林还在那张桌子后面，抬头惊恐地看着林远。林远甚至没有看他，径直走向地下车库。车轮碾过沥青路面的声音在夜色中格外清晰，像是一首急促的安魂曲。

今晚，要么黎明，要么长夜。

林远踩下油门，发动机发出野兽般的轰鸣，黑色的轿车如离弦之箭般射入城市的深渊。在后视镜里，办公室那扇唯一的窗户，灯光依旧亮着，孤独而倔强地悬浮在黑暗之中。他没有回头，只是紧紧握住了方向盘，指关节因为用力而发出轻微的声响。前方是无尽的未知，但在那未知的尽头，答案正在等待着他。
