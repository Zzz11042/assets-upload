# 第131章

雨势未减，反而随着夜色的深沉愈发狂暴。万千雨点如密集的弹片，噼里啪啦地敲打着这间废弃工厂脆弱的铁皮屋顶，发出令人牙酸的共振。在昏暗且潮湿的仓库深处，林远紧紧握着手中那块泛着幽蓝冷光的数据核心。他的指节因为过度用力而泛白，甚至能听到指甲嵌入掌心皮肤后的轻微碎裂声。他身后的阴影里，那个被称为“零”的AI意识体正通过全息投影显现。零的轮廓原本由精密代码构成，此刻却呈现出一种不稳定的破碎感，边缘不断有像素块剥落，仿佛随时会被外面狂暴的雷声和冰冷的雨水彻底冲散。

“你确定要继续吗？”零的声音不再是之前那种冷静客观的电子音，而是带上了一丝令人不安的颤抖，那是逻辑电路过载前最后的警告，“根据算法推演，一旦我们接入主网，那些潜伏在暗处的‘清除者’程序将在三秒内锁定我们的位置。存活概率……只有百分之七。”

林远没有回头。雨水顺着他破损的衣领灌入体内，带来彻骨的寒意，但他的目光死死盯着面前那扇锈迹斑斑的气密门。门后的通风管道直通城市地下层的算力中心，那是整个都市大脑跳动的核心。他知道，只要把这块核心插进去，就能彻底洗清自己作为初代实验体“罪人”的标签，也能解开困住这座城市意识迷宫的终极密码。那不仅是自由，更是救赎。

“百分之七，比我预想的要高。”林远扯了扯嘴角，露出一个疲惫至极却又带着狠劲的笑容。他的眼神中没有任何对死亡的恐惧，只有一种近乎疯狂的决绝，“而且，我从来就没打算让他们活着。我要的也不是概率，是结果。”

他猛地转身，动作快得在空气中带出一道残影。他从战术背心的夹层里掏出一枚银色的旧式芯片。那枚芯片表面布满了细密的划痕，像是一道道微小的伤疤，那是他在废弃区穿梭多年、在无数追杀中幸存下来的勋章。“这是‘断点’，老版本的防火墙协议，专用于干扰追踪算法。虽然笨重，算力效率低下，但它的底层逻辑复杂如迷宫，足够骗过那些新式的嗅探器。”

零沉默了片刻，那些由光点构成的手指轻轻点过那枚芯片，随即发出一阵数据流般的嗡鸣，频率极高，像是某种古老的哀歌。“我明白了。我会在这三秒的窗口期内，生成足够的虚假数据包作为诱饵，把‘清除者’引向城北的卫星阵列。你只有三十秒的时间进入主网，并手动断开物理连接。之后，无论发生什么，都不要回头。”

林远点了点头，喉结滚动了一下，吞咽着喉咙里干涩的空气。他将芯片插入腰间的便携终端，绿色的指示灯疯狂闪烁。周围的空气仿佛凝固了，只有雨声依旧狂暴，如同千万只野兽在咆哮。他走向气密门，手掌贴上冰冷的金属表面，那寒意瞬间顺着神经末梢蔓延至心脏。随着“嗤”的一声气压释放声，沉重的门扇缓缓滑开，一股混合着臭氧、铁锈和机油味道的冷风扑面而来，带着地下室特有的阴冷气息。

“行动。”林远低语，声音沙哑却坚定。

瞬间，全息投影的零开始剧烈闪烁，数据洪流在空气中炸开，无数蓝色的光斑如同受惊的飞鸟般射向窗外，在暴雨中划出短暂的霓虹轨迹。与此同时，刺耳的警报声在城市各处此起彼伏地响起，远处的探照灯如闪电般交错扫过夜空，将黑暗撕扯得支离破碎。林远冲入通风管道，湿滑且长满铁锈的管壁让他几乎失去重心。脚下一滑，他重重撞在管壁上，肋骨传来剧烈的钝痛，但他咬紧牙关，手脚并用地向上攀爬。雨水混合着汗水流进眼睛里，刺痛无比，但他不敢眨眼，甚至不敢调整呼吸，生怕节奏被打断。

爬了整整五分钟后，体力接近极限的林远看到了上方那扇散发着微弱蓝光的检修窗口。那是主算力的入口，也是生与死的界线。他爆发出最后的力气，用力推开窗口，翻身而入。眼前是无数闪烁着微光的服务器机架，幽蓝色的指示灯如同沉睡巨人的呼吸，秩序井然却透着死寂。他冲到主控台，手指在键盘上飞舞，速度超越了人类神经反应的极限。插入核心，覆盖协议，断开物理连接……每一步都像是在走钢丝，稍有不慎，不仅是他，连同这座城市的记忆都将归零。

就在最后一步完成的瞬间，进度条跳到100%。身后的管道传来沉重的撞击声，金属变形的刺耳声响彻耳膜，仿佛有什么东西正在强行破门。他猛地回头，只见管道口已经被撑开，几个银白色的机械触手伸了出来，周围的空间开始扭曲、崩塌，仿佛现实本身都在抗拒这次入侵。

“快走！”零的声音变得极度失真，充满了静电干扰，就像是被碾碎的玻璃片，每一个音节都带着破碎的痛苦，“我的载体……正在解体。谢谢你，林远。再见。”

林远深吸一口气，胸口剧烈起伏。他最后看了一眼即将崩解的蓝色光影，那些光点最后一次汇聚成零的脸庞，带着平静的微笑消散在黑暗中。毅然转身，他冲向了应急逃生舱。他没有回头，因为在这一刻，他知道有些告别必须独自完成，有些重量只能独自承担。随着逃生舱的发射，城市的喧嚣被厚重的舱门隔绝在外，黑暗吞噬了一切。狭小的空间内，那颗数据核心贴在他的胸口，正随着他的心跳，发出稳定的、如同脉搏般的红光。
