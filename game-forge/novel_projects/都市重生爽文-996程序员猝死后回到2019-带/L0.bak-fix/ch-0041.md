# 火中取栗

浓烟像是一条活着的黑色巨蟒，在走廊里肆意翻滚、挤压，贪婪地吞噬着最后一丝可供呼吸的氧气。空气稀薄得令人窒息，每一次呼吸都像是在吞咽滚烫的砂砾，灼痛感瞬间从鼻腔蔓延至肺腑，仿佛无数根烧红的铁丝在气管内穿梭。视线所及之处，一片混沌的灰黄，分不清哪里是墙，哪里是天花板，只有头顶那盏闪烁着危险红光的应急灯，将整条走廊染成令人毛骨悚然的血色。

林默背靠着冰冷的墙壁，剧烈地咳嗽着，胸腔里像是有一团火在烧。他的右臂还在隐隐作痛，那是刚才在躲避第一波搜查时撞伤留下的后遗症，但现在，这种钝痛比起肺部的剧烈灼烧来说，简直微不足道。墙壁上的防火漆开始冒出焦糊的白烟，发出“滋滋”的爆裂声，像是在低声狞笑。

“他们不会放过你的。”

一个低沉而冰冷的声音从楼梯口的方向传来，伴随而来的是军靴踩在大理石地面上的回响。那节奏整齐划一，带着令人窒息的压迫感，正一步步逼近。每一步落下，都像是敲在林默紧绷的神经上。

林默的心跳漏了一拍，冷汗顺着鬓角滑落。追兵到了。

他迅速低头，目光在昏暗的光线中艰难扫过脚边。那个银色的微型U盘正静静地躺在一块翘起的地砖缝隙里，在红光下泛着寒光。这是整件事的核心，里面装着足以撼动整个局域网络的底层代码。如果没有它，之前所有牺牲掉的人都将毫无意义；但如果带着它落入他们手中，等待他的必将是比火焰更残酷的命运。

火焰的咆哮声越来越响，热浪扭曲了空气，连声音都变得失真。林默咬紧牙关，强忍着咳嗽的冲动，迅速弯腰捡起U盘，紧紧攥在掌心。冰凉的金属触感给他带来了一丝虚幻的安全感，他迅速将其塞进内衬衣的口袋，并拉好拉链，确保它不会因体温而变得显眼。

“在那边！”

前方的脚步声停顿了一瞬，随即爆发出一阵急促的奔跑声。他们看到他了。枪声即将响起，林默没有犹豫，转身冲向了走廊尽头。那里有一扇厚重的防火门，门后连接着设备层。他知道设备层里有一个通往外部维护通道的检修口，那是唯一的生路。

然而，就在他伸手触碰到门把手的瞬间，身后传来了一声清脆的枪响。子弹擦着他的耳边飞过，带起一阵热流，击碎了一边的玻璃幕墙，玻璃碎片如雨点般落下，折射出细碎的光影。林默的心脏猛地收缩，恐惧如潮水般涌来，但他不敢回头，只能将求生的本能转化为狂奔的动力。

“别跑！”怒吼声近在咫尺，几乎贴着他的后背。

林默猛地推开防火门，跌跌撞地冲进了设备层。这里比主楼更热，巨大的服务器机柜排列如迷宫，散热风扇还在疯狂地旋转，发出震耳欲聋的轰鸣。火焰已经开始舔舐机器的边缘，线缆燃烧的刺鼻味道让人头晕目眩，眼前的景象宛如地狱深处。

他在一台巨大的立式机柜前停下，那里有一个黑色的金属百叶窗——通风管道入口。管道很窄，只容得下一个人勉强匍匐进入。林默深吸了一口这充满焦味的空气，推开百叶窗，侧身钻了进去。

管道内部漆黑一片，狭窄得令人产生强烈的幽闭恐惧感。四周全是冰冷的金属壁，每一次爬行都伴随着衣料与金属摩擦的刺耳声响。他只能依靠手肘和膝盖前进，身体几乎与金属内壁摩擦，泥土和血液的味道混杂在一起。外面追兵的喊声和枪声被厚重的金属壁隔绝，听起来闷闷的，但依然透着不容置疑的杀意。

林默不敢有丝毫停歇，他必须在记忆深处搜索管道的走向。图纸显示这条管道通向大楼北侧的消防塔，而消防塔的外侧连接着应急逃生滑梯。那是唯一能让他离开这栋楼的机会。

“吱嘎——”

金属摩擦的声音在安静的管道里显得格外刺耳，并非出自他身体摩擦的声音，而是前方某处的异响。林默心中一紧，难道有人发现了这条暗道？

他停下动作，屏住呼吸，心脏在胸腔里剧烈撞击肋骨。前方传来微弱的反光，那是管道另一侧的出口。没有等待的时间，身后的热浪越来越强，管道壁烫手，他的手掌已经被烫出了水泡，皮肤泛起红肿。他不得不加快速度向前爬行，指甲在金属壁上刮出火花。

“咔哒。”

当他爬出管道，跌落在消防塔的平台上时，身后的铁门被猛地撞开。几道手电筒的光束刺破黑暗，像利剑一样照亮了平台边缘。光束扫过他的脸，带来刺目的强光。

“林默！站住！”

林默没有回头。他纵身一跃，跳上了滑动的金属应急滑梯。滑道倾斜度极大，风在耳边呼啸，摩擦力让他的制服迅速磨损，皮肤火辣辣地疼，甚至能闻到布料烧焦的味道。他在滑道上翻滚、跳跃，利用惯性避开滑道上残留的滚烫金属碎片，最终在塔底落地。

落地的那一刻，膝盖传来剧痛，但他立刻翻滚起身，钻进了附近的灌木丛中。身后，追兵赶到平台边缘，探出身子向下张望，却只看到一片漆黑的夜色和摇曳的树影。手电筒的光束在林中乱扫，光束在树叶间跳跃，却找不到任何踪迹。他们咒骂着，只能暂时放弃。

林默趴在冰冷的泥土上，大口呼吸着夜晚清冷的空气，心脏剧烈跳动，几乎要跳出嗓子眼。他颤抖着手，从口袋里掏出那个U盘。金属外壳已经变得滚烫，但在夜色中，它依然闪烁着微弱的蓝光，像是在嘲笑他的挣扎。

他找到了一台随身携带的便携式终端，将U盘插入接口。屏幕亮起，原本期待的进度条没有出现，取而代之的是一个红色的警告框，刺眼的红光映照在他布满灰尘的脸上：

“[ERROR: DATA CORRUPTED]”

“[REQUIRES SPECIFIC DECODER: KEY-OMEGA]”

林默的瞳孔剧烈收缩。数据损坏？这不可能。他出发前检查过无数次，每一个字节都确认无误。除非……除非在转移过程中，环境的高温和震动触发了某种自毁机制，或者，数据本身就是加密的，而这个“特定解码器”，只有他们组织内部的核心人员才拥有。

他抬起头，望向远处城市灯火通明的天际线。烟雾还未散尽，追兵的警笛声在远处隐约回荡，像是一首催命的挽歌。他手里攥着那个看似毫无用处的U盘，感觉自己像是从火中取出的栗子，虽然保住了性命，但核心的部分，似乎已经支离破碎。想要读取真相，他必须回到那个危险的中心，找到那个“解码器”，而这意味着，他必须重新踏入地狱，去直面那些想要置他于死地的人。
