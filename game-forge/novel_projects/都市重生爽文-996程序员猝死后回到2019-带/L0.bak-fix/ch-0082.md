# 第82章

风在深夜的窗外咆哮，发出如同野兽呜咽般的声响，猛烈地撞击着那扇摇摇欲坠的木窗。林远坐在书桌前，手中的钢笔悬在半空，滴落的墨迹在泛黄的纸张上晕开一个巨大的黑点，像是一个无法闭合的血痂。

“你终于肯让我看完了。”

站在门边的老陈声音沙哑，仿佛沙砾在喉咙里摩擦。他没有开灯，整个房间沉浸在一片浑浊的暗影中，只有林远书桌那盏昏黄的台灯投下微弱的光晕，将两人的影子拉得细长而扭曲，投射在身后的墙面上，像是一双双正在挣扎的鬼魂。

林远缓缓抬起头，目光越过老陈，落在书桌上那封已经被拆开却未读完的信上。信封上的火漆碎裂，曾经密不透风的红色蜡油如今像是一具具干瘪的尸体，瘫软在桌角。

“我以为我会恨的。”林远的声音很轻，轻到几乎被窗外的风雨声吞没。他推了推鼻梁上的眼镜，镜片后那双原本锐利如刀的眼睛此刻布满了血丝，眼底是深不见底的疲惫与一种刚刚破碎后又试图重组的荒谬感，“我准备了三年，甚至设想过在见到他时，我该用那种充满仇恨的眼神去审视他，用那种决绝的语气去宣布我们的决裂。但我错了。”

老陈沉默了片刻，终于向前迈了一步，地板发出一声沉闷的哀鸣。“错得多么彻底？”

“彻底到我想笑。”林远苦笑一声，手指无意识地摩挲着那封信的边缘，指腹因为紧张而微微发白，“我原以为他会给我答案，甚至会给我忏悔。但我看到的，只是一份冰冷的、甚至可以说是残忍的客观记录。他说，在那场大火中，他的反应不是出于爱，而是出于一种被恐惧支配的本能。他描述自己是如何在最后关头因为极度的惊慌而忽略了身后的火舌，如何在那片火海中被某种巨大的无力感吞噬。”

林远抬起头，目光灼灼地盯着老陈，仿佛在透过老陈看向那个早已死去的“父亲”，或者是那个从未真正存在的父亲。“你明白吗？老陈？他承认自己是一个懦夫。一个在那种极端情境下，连最基本的保护本能都失灵了的懦夫。他甚至没有把我推开，不是因为他不想救我，而是因为他当时根本不知道自己该如何去推开我。那一刻，他不是父亲，也不是凶手，他是一个和任何一个陷入火场的普通人一样，在恐惧中彻底崩溃的普通人。”

老陈没有说话，只是静静地看着林远。火光在跳动的瞬间照亮了老陈布满皱纹的脸庞，那张脸上看不出任何悔意，只有一种近乎旁观者的冷静。这冷静比任何言语的侮辱都要刺骨。

“这就是你所谓的真相？”林远猛地站起身，椅子在地板上刮出刺耳的尖响。他抓起那封信，纸张在颤抖的手指中发出细微的沙沙声，“一份剖析自己弱点的记录？他连一句对不起都没有。不，他甚至没有用‘对不起’这种廉价的词汇来作为借口。他只是陈述事实。”

“事实。”老陈突然重复了这个词，嘴角勾起一抹意味不明的弧度，“林远，事实往往比谎言更不可饶恕，对吗？谎言至少还留有自我安慰的空间，而事实，只留下无尽的绝望。”

林远愣住了，那股原本翻涌在胸口的愤怒瞬间凝固。他再次跌坐回椅子上，双手深深地插入发间，指节因为用力而泛白。

“我想起了那个晚上。”林远的声音开始出现了一丝不易察觉的颤抖，像是从极寒之地传来的风声，“火光照亮了半边的天空，浓烟的味道呛得我眼泪直流。我躲在床板下，透过缝隙看着那个我认为是唯一能带我出去的人，看着他被困在门口。他没有回头。哪怕一次都没有。”

老陈缓缓走到桌边，将那盏灯关掉了。房间彻底陷入黑暗，连那微弱的光晕也消失了。窗外，一道闪电劈下，瞬间将整个房间照得惨白，林远和老陈的身影在这一刹那暴露无遗。

“但这一次，”老陈的声音在黑暗中显得格外清晰，仿佛贴着林远的耳朵低语，“你终于知道，他没有回头，是因为他当时也被困住了。他的腿被门框卡住了。”

林远闭上了眼睛，脑海中瞬间涌入了那些他从未深究过的画面。门框变形的声音，老人痛苦的喘息，以及那种在黑暗中摸索却无论如何都无法挣脱的绝望。

“他被困住了。”林远喃喃道，“就像我也被困在这三年的仇恨里一样。”

“你恨的不是他，林远。”老陈的声音渐渐远去，似乎在黑暗中退到了角落，“你恨的是那个因为他的懦弱而不得不独自面对火海、独自面对死亡的你。你在这三年里，都在试图从他那只永远无法给出爱的手里，去索取一份迟来的安慰。但你忘了一件事，恨，也是一份沉重的羁绊。它证明了你曾经渴望过爱。”

林远猛地睁开眼，在黑暗中，他的瞳孔因为适应了光线而放大了很多倍，显得深邃而空洞。他看着那封在黑暗中无法看清的信，心中那片死灰般的废墟上，似乎有一根不知名的野草正顽强地、艰难地探出头来。

“所以呢？”林远问，声音依旧平静，但这份平静不再是之前的麻木，而是一种暴风雨后的死寂，“告诉我这一切，就是为了告诉我，我三年的恨都是荒谬的吗？”

老陈没有回答，只是轻轻推开了门。风涌了进来，吹得林远的头发狂舞。在门外的黑暗深处，似乎有什么东西在注视着他们，冰冷、无声，等待着林远迈出下一步。

林远站起身，整理了一下衣角。他知道，无论门外等待的是什么，那个躲在床板下、在黑暗中恐惧哭泣的男孩，已经永远留在了那场大火里了。而从今往后，走出这个房间的，只有他自己。
