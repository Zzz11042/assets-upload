# 迷雾深处

雨水像断了线的珠子，噼里啪啦地砸在废弃工业区的铁皮屋顶上，发出令人牙酸的轰响。那声音在寂静的废墟中显得格外刺耳，仿佛无数细小的锤子在敲击着林远紧绷的神经，每一声都像是直接敲在他的心尖上。他紧紧捂住腹部那道还在渗血的伤口，温热的血液顺着指缝滑落，混着冰冷的雨水，在地面上溅开深色的花，瞬间就被泥泞吞噬。他踉跄着躲进一间半坍塌的仓库，潮湿腐烂的气味扑面而来，混合着铁锈、霉变木材和浓重的血腥味，令人作呕。脚下的积水没过脚踝，每一步都伴随着令人不安的湿滑感。

他的呼吸急促而沉重，每一次胸腔的扩张都伴随着剧烈的刺痛，仿佛有一把钝刀在肋骨间来回拉扯。就在五分钟前，那群黑衣人的枪口还抵在他的脸上，冰冷的金属触感隔着单薄的衣物刺透骨髓，死亡的阴影几乎将他彻底笼罩，连指尖的温度都消失了。然而，那个一直沉默寡言、代号“幽灵”的同伴，却在这一瞬间拔枪，以不可思议的速度扫清了四周的威胁。枪声在狭小的空间内回荡，每一次震动都让林远的心跳漏拍半拍，耳鸣声尖锐得几乎让人失聪。但在那片硝烟弥漫的虚空中，只有幽灵的身影如同一尊黑色的雕塑，不可撼动，子弹在他周围划出致命的弧线，却无一例外地偏离了目标。

“别发呆，林远。”幽灵的声音沙哑，带着一丝从未有过的疲惫。他靠在湿漉漉的墙边，左臂垂在身侧，衣袖已经被鲜血浸透，深红色的液体顺着袖口滴落在积水中，显然也受了不轻的伤。尽管伤势严重，他手中的枪依然稳稳地指着门口，警惕地捕捉着每一丝细微的动静，枪口微微上扬，随着窗外模糊的脚步声左右微调，“他们还在搜索。那支‘清除队’不是普通的安保，是隶属于‘深渊’组织最高权限的猎犬。一旦你被抓住，关于‘起源’核心的所有线索都会被抹去，连同你一起，变成系统里的一个数据错误。”

林远颤抖着从怀里掏出一块泛黄的芯片，这是他刚从“深渊”位于港口的秘密据点偷来的核心数据载体。芯片上的红灯疯狂闪烁，频率越来越快，仿佛一颗即将爆炸的心脏，在黑暗中显得格外刺眼，那光芒映照在林远苍白的脸上，忽明忽暗。他看着眼前这个在枪林弹雨中始终挡在自己身前的男人，心中涌起一股复杂的情绪。多年来，幽灵一直是他在黑暗中唯一的依靠，是他混乱世界中唯一的锚点，但他从未真正了解过对方。那个男人总是沉默如谜，眼神深邃得让人看不清底细，像是一口枯井，投石无回响。在生死迫近的绝境下，某种直觉驱使林远问道：“你到底是谁？为什么‘深渊’会不惜一切代价追杀你和我？”

幽灵没有立刻回答。他低头看着自己那双沾满血污的手，指节因用力过度而泛白，那是长期握枪或处于极度紧张状态留下的痕迹，皮肤粗糙，布满老茧。雨水顺着他的发梢滴落，在那一刻，他眼中那层冷漠的面具似乎出现了一道细微的裂痕，闪过一丝难以言喻的哀伤，那是林远从未在这双眼里见过的表情。他抬起头，目光穿过厚重的迷雾，直直地看向林远，声音轻得像是一声叹息：“因为我不叫幽灵。我是陆沉。”

这个名字如同惊雷般在林远脑海中炸响。陆沉？那个在十年前‘初号实验’事故中神秘失踪，被官方宣布死亡，却在民间传说中被誉为天才黑客与反抗军领袖的人？林远难以置信地瞪大了眼睛，浑身僵硬，仿佛被施了定身咒，连呼吸都停滞了半拍。他回忆起过去每一次并肩作战时，对方下意识保护他的动作，以及那种对“深渊”系统架构了如指掌的本能反应，所有的碎片在这一刻拼凑完整。那些看似偶然的巧合，其实是精心设计的守护；那些偶尔流露出的对旧时代技术的熟悉，不仅是经验，更是血脉的传承。原来，他一直在被一个幽灵所守护，或者说，被一个活着的传奇所庇护。

“你……你是陆沉？”林远的声音干涩得几乎发不出声，喉咙像是被什么东西扼住，带着不可思议的沙哑。

“不，陆沉是我已故的父亲。”幽灵——不，此刻他更想被称为陆离——纠正道，嘴角扯出一抹苦涩的笑，那笑容中带着一丝解脱，也带着无尽的沉重，“我继承了他的意志，也继承了他留下的唯一秘密。这枚芯片里存储的不仅仅是‘深渊’的实验数据，更是‘起源’计划的核心代码。它能证明‘深渊’一直在通过控制人类意识来维持统治，而破解这一切的密钥，就藏在我家族的基因密码里，也藏在你的血统里。”他顿了顿，眼神中闪过一丝决绝，直视着林远，“他们追杀你，是因为你无意间触动了这个秘密的开关。而我，只是这把钥匙最后的守护者，也是你的引路人。”

窗外的夜色更加浓重了。远处的探照灯光束在雾中疯狂扫射，切割着黑暗，形成一道道惨白的光柱。直升机的轰鸣声由远及近，震得破旧的窗玻璃嗡嗡作响，灰尘纷纷落下。陆离从地上捡起一枚信号弹，熟练地拉掉引信，扔向窗外。红色的火光在漆黑的夜空中划出一道耀眼的轨迹，那是撤离船队的坐标，也是生还的最后希望，在灰暗的世界中显得如此珍贵。

他转身面对林远，伸手拍了拍他的肩膀，力道沉重而坚定，仿佛要将某种信念传递过去：“跑吧，林远。去解开代码，去终结这一切。我会在这里吸引他们的注意力，为你争取时间。”

林远死死抓住陆离的手臂，眼中满是震惊与悲凉，泪水不知何时混入雨水，模糊了视线：“你可以跟我一起走！我们可以共同破解，不需要你一个人去送死……”

陆离摇了摇头，手上的动作温柔却不容拒绝，将林远推向唯一的逃生通道，声音在引擎的轰鸣中逐渐消散，却字字清晰：“这是陆沉未完成的责任，现在由我来延续。记住，不要回头，活下去，把真相带出去。”

随着一声巨响，仓库外的爆炸掀起巨大的尘土与碎片，整个空间剧烈震动，视野瞬间被橙红色的火光填满。林远在混乱中跌跌撞撞地冲出阴影，肺部的空气仿佛被瞬间抽空，心脏剧烈撞击着肋骨。他回头望去，只看见陆离孤身一人站在火光与枪火交织的中心，身影在迷雾中显得既渺小又高大，宛如一座沉默的丰碑，最终被黑暗彻底吞没。而他手中紧攥的芯片，依然在黑暗中顽强地闪烁着红光，指引着通往真相的唯一道路，也指引着他必须活下去的理由。
