# 第80章

夜色如墨，浓稠得几乎要滴出水来。雨势渐歇，檐角偶尔坠下的一两滴残响，在空旷的屋内被无限放大，叩击着青石板地面上那一层薄薄的积水，发出冷硬的脆音。沈砚舟并未立刻起身，他仍维持着方才那个半躺的姿态，身躯沉重地陷在那张陈旧的太师椅里。他的指尖轻轻摩挲着袖口上那枚早已黯淡的玉扣，指腹下传来的触感冰凉且粗糙。

那玉扣是三年前在边陲城破之夜，他从敌将尸体上搜来的。彼时鲜血未干，染红了半边衣襟，他以为那是战利品，是活下来的证明。如今，它只剩下一道细微的裂纹，在昏黄的灯下泛着死气沉沉的灰白，像极了他们之间千疮百孔的旧事，无法修补，只能忍耐。

“你一直在看。”他忽然开口，声音沙哑，仿佛砂纸磨过锈铁，带着常年未愈的喉疾特有的颗粒感。他没有转头，也没有看向任何人，只是死死盯着房梁上那一小片透进月光的水渍，那水渍随着光影摇曳，像是一只窥视的眼睛。

角落里，一直没出声的苏若水慢慢将折扇合拢。扇骨撞击的轻响在寂静中显得格外清晰。她并未否认，只是轻笑了一声，那笑声极轻，像是一片落叶被风卷起又迅速落下，带着几分疏离的凉意，刮过沈砚舟原本就紧绷的神经。

她站起身，裙摆扫过地面，发出细微的沙沙声。灯火在她眼中摇曳，将那双总是含着清浅笑意的眸子染得有些晦暗不明，深不见底。

“沈师兄，”她唤道，语调温婉，尾音微微上扬，却藏着不易察觉的尖锐，“这玉扣，终究是死物。死物不会说话，但会藏污纳垢。你拿着它，难道是在提醒自已，当年那一刀，为何没能劈开他的命，只劈开了这玉？”

沈砚舟的手指猛地一僵，指尖的血液仿佛瞬间冻结。那是他心底最隐秘的痛处，也是他三年来如鲠在喉的刺。当年那一刀，他为了救苏若水，误伤了当时的盟友，也就是如今权倾朝野的丞相世子。那一刀，不仅斩断了世子的生机，也斩断了他与整个世家门阀的最后一丝联系。他以为自己是在护道，以为那是侠气使然，可如今想来，那更像是一次蓄谋已久的背叛。他背弃了师门的规矩，背弃了盟友的信任，只为了护住眼前这个看似柔弱实则心狠手辣的女子。

“我没有。”他低声道，像是在说服自己，又像是在向虚无辩解。他终于撑着桌角坐起，身体微微佝偻，肩背上的旧伤在起身的瞬间隐隐作痛，在雨后的湿冷气中钻心地酸胀，仿佛有人拿钝刀在骨肉间锯动。他抬头，目光灼灼地看向苏若水，那眼神里布着红血丝，透着极度的疲惫，更有一种近乎绝望的清醒。

“若水，你今日来，不仅是为问这玉扣。外头的探子，我已经听到了。”他顿了顿，压低了声音，“丞相府的马车，停在巷口已有半个时辰。车轮碾过泥地的声音，我听得一清二楚。”

苏若水脸上的笑意瞬间凝固，随即化作一抹复杂的悲悯，仿佛看着一只落入陷阱却还在挣扎的困兽。她走近两步，伸出纤细如葱白的手指，轻轻挑开了沈砚舟领口的衣襟。动作轻柔得近乎暧昧，却让沈砚舟浑身僵硬。在昏暗的灯下，她看到了他胸口那道几乎愈合却仍狰狞可怖的疤痕，那是三年前那场大火留下的印记，蜿蜒如蜈蚣，爬满了他的心脏位置。

“他们不是来救你的，”她轻声说道，语气平淡得可怕，仿佛只是在陈述一个无关紧要的天气事实，“他们是来收殓的。沈师兄，你以为你还能逃到哪里去？这京城的大牢，已经为你留好了一间房。而外面那些所谓的‘江湖义士’，不过是丞相手里养活的刀。刀把子，一直攥在人家手里。”

沈砚舟感到一股寒意顺着脊背疯狂爬升，比窗外的冷雨更甚，直透骨髓。他想起近日以来，那些看似巧合的援手，那些总是慢半拍出现的敌人，那些在关键时刻突然出现的援军。他一直以为这是友军的协作，是尚存的人间正气。如今听苏若水这么一说，所有的线索都在脑海中疯狂拼接，拼凑出一个残酷而冰冷的真相——他早已不是一名独行的剑客，而是一场巨大棋局中，一枚被精心操控的棋子。他每一次的出招，每一次的退缩，甚至每一次的“幸存”，都在对方的计算之中。

“若水……”他的声音颤抖起来，不再是刚才的隐忍，而是带着一种濒临崩溃的恳求，仿佛抓住了最后一根浮木，“告诉我，还有没有变数？那个被关在天牢深处的证人，他拼死也要传出的‘第三把钥匙’，究竟是谁？总得有个底线，对吗？”

苏若水没有回答。她只是缓缓后退，退到灯光照不到的阴影里。她的轮廓在黑暗中变得模糊，如同鬼魅，声音却清晰得令人战栗，每一个字都像钉子一样钉进沈砚舟的耳膜：“没有钥匙。师兄，根本就没有什么机关密码。所谓的第三把钥匙，只是丞相为了让你死得更绝望，而特意喂给你的最后一根骨头。你越去追，越心死，他越能看清你的软肋，让你无法翻身。”

话毕，她的身影竟在阴影中消散，仿佛从未出现过，只留下一地清冷的月光，和空气中尚未散去的、淡淡的檀香。那香气甜腻得让人作呕，带着腐朽的味道。沈砚舟猛地抓起案上的茶盏，狠狠砸在墙上。碎裂的声音在寂静的夜里显得格外刺耳，茶渍溅满了斑驳的墙壁，如同血痕。他盯着那面墙壁，眼中怒火与绝望交织，最终化为一片死寂的灰暗。

他知道，从这一刻起，他再也无法回头。窗外，丞相府的马车车轮碾过积水的声音再次传来，沉闷而沉重，一步步逼近这方寸之间的屋室。决战，已至。
