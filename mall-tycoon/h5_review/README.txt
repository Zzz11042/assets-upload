# 商场大亨 — H5 版提审包(给 TapTap 审核/试玩)

单文件 H5 可玩版,无任何外部依赖,浏览器打开即玩(已做触屏/PWA 适配,手机浏览器亦可)。

## 运行方式
- 桌面:双击 `index.html`(浏览器打开)
- 手机:把 `index.html` 发到手机浏览器打开

## 玩法规则
1. 点空铺位建铺(默认建当前买得起的第一种铺位)
2. 再点已建铺位升级(等级+1)
3. 长按铺位 2 秒拆除(返还 50% 建造费)
4. 每 30 秒自动过一天,弹当日财报(收入/维护/结余)
5. 顶部事件条随机出现:🎉周末促销(客流×1.5) 或 🔧检修(×0.5)
6. 资金≥¥20000 时点"扩建",开放最右一列铺位
7. 攒到 ¥100,000 达成 🏆 扩张成功

## 数值
- 开局资金 ¥20,000
- 5 种铺位:咖啡(¥1500) / 超市(¥3000) / 游戏厅(¥5000) / 电影(¥9000) / 酒店(¥18000),最高 Lv5
- 4 铺 Lv1 日净约 ¥3.2 万;达成 ¥100,000 约 8-9 个游戏日

## 存档
浏览器 localStorage 自动保存;点"重开"清空。
