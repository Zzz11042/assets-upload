# 参考资料 — 《潜伏》《渗透》风格笔记（ref-001）

> 来源：本地知识卡 `dsh-kb/06-资源/2026-10-29_lantian-shentou-style.md`（联网调研沉淀）。

## 可学结构（非原文）

### 潜伏（余则成视角）
1. **人物先立后事**：每个出场角色一个性格锚点，情节服务人物。
2. **对白短密有回镖**：一句顶三句，潜台词密度高（"你嘴放干净点"式）。
3. **细节积蓄不靠人设速成**：情绪不直陈，给一个动作/微表情（"蹙眉"、"脸亮了又暗"）。
4. **细节铺排真实感**：机关设置、职位、称呼、装备的准确性。
5. **多线暗线交织**：节点处三线交汇（鬼佬账线/军阀线/白宫记忆线）。

### 渗透（沙溢版许忠义，卧底哲学）
1. **明牌摊牌**："我都明牌了，你怎么跟我打？"——身份暴露边缘反而更从容。
2. **利益腐蚀**："能用钱解决就用钱解决！"——贿赂不写动机，写对方的"嘴"（具体好处）。
3. **自嘲**："干啥啥不行，投机倒把第一名"——主角自我定位梗。
4. **价值锚点**："你们明知我是卧底但又离不开我！"——让反派离不开主角。

## 人物细节描写"五类锚点"（落地店小二）

| 类别 | 店小二写法 |
|---|---|
| 微表情 | 不解释情绪，给一个动作（鬼佬数金表链子=贪；忠义先算账再开口） |
| 口癖/称呼 | 鬼佬咬重"自己"二字；上校称忠义"会算账的" |
| 道具锚 | 金表/金烟（鬼佬），每 3 章出现一次；账本（忠义） |
| 空间习惯 | 忠义在沙漠据点的"账房位"（他固定站的位置=权力位） |
| 沉默处理 | 关键对质时让角色"不答"或"答岔"（忠义装怂，鬼佬沉默=心虚） |

## 禁用（反 AI 味 + 防抄袭）
- 不直陈情绪（"他感到紧张"）→ 用动作。
- 不堆景物抒情 → 细节服务对白张力。
- 不照抄《潜伏》《渗透》台词 → 只学结构，改成店小二的账房语境。
