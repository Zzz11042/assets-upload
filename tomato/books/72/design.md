# 《七十二楼》设计文档
## 末日生存丧尸文（紧张刺激·逃杀反杀·无系统）

> 调研来源：番茄写实系丧尸文《回到黎明》（无系统无异能，纯生存）、《丧尸专列》（公路叙事）、逃杀文热点（暴雪山庄+倒计时+封闭空间）、黄金三章节奏（300字入冲突/800字身体感官/1000字小爽点）、"开局即绝境"例。

## 一、核心设定

- **书名**：七十二楼
- **频道**：男频，末世·丧尸·生存（逃杀反杀型，写实系，无系统无异能）
- **一句话**：病毒爆发第七天，我被困在72层高的住宅楼里。楼里的感染者比活人多，唯一活命的机会是楼顶的军方信标——但只有活人才能启动。我，一个住68层的独居者，要在72层楼里，从68层杀到1层，再回到72层。楼里最危险的事，不是丧尸，是"活人"。
- **主角**：林深，35岁，独居，住68层。病毒爆发前是建筑工程师（认楼，认结构，认管道井），金手指=建筑结构知识（知道哪面墙是承重、哪段楼梯是逃生通道、哪个楼层有检修井可以垂直通行）。无异能无系统，冷静=职业习惯。
- **紧张感三件套**：①每章至少1次"声音事件"（楼里铁律：静=活，声=死，感染者循声而来）②每章至少1个倒计时（信标每72小时充能一次，错过就再等72小时）③每章末150字内必留钩

## 二、世界观（第7天状态）

- 城市：临江市，病毒第7天爆发，全城封死。72层高层住宅"临江苑"，480户，爆发时被困住。
- 感染者：循声、循热，不循光（与雾夜列车设定不同——本书无"雾"，有"声"）。72层楼里，感染者集中在低层（1-30层），因为低层入口多、活人往高跑。31-60层是"缓冲带"（感染者少，但活人也少，物资少）。61-72层是"顶层区"（活人多，感染者少，但有军方信标在72层顶——只有活人按启动键，信标才能向空中发射72小时一次的"活人坐标"，军方才会派救援机）。
- 规则：
  1. 楼里不许大声（声=死）
  2. 信标每72小时充能一次，充能期间只有活人能按
  3. 低层感染者在夜间（22:00-05:00）活跃度翻倍（热辐射）
  4. 管道井可以垂直通行，但管道井里有"东西"（第3章起）
- 势力：
  1. 军方（控制信标，只信坐标，不派人进楼——第7章+才出现）
  2. "顶层会"（61-72层的活人联盟，自封"临时管委会"，控制物资，收"楼税"）
  3. "低层猎手"（31-60层的活人小团体，专门猎杀低层感染者取"组织液"（能暂时抑制感染）——灰色角色，第5章+出现）
  4. 感染者（不是敌人，是"地形"——会爬、会咬、会循声，但不懂"楼"）

## 三、主线（紧张刺激线）

林深要从68层到1层（取"组织液"——他68层的邻居已经感染，需要抑制），再回到72层（按信标）。每一层楼=一个封闭空间悬疑，每一层=一个"声音事件"。主线悬念：楼里最危险的不是感染者，是"顶层会"——他们故意不按信标，因为按了，军方来了，他们的"楼税"就没了。

## 四、黄金三章细纲（第1章今天写）

| 列 | 内容 |
|---|---|
| 场景 | 第7天凌晨03:00，68层，林深被"声音"吵醒 |
| 冲突 | 68层的邻居（老陈）已经感染，正在用头撞门。林深要决定：开门（老陈是活人）还是不开（老陈是感染者）。同时，72层信标的"72小时充能倒计时"只剩71小时58分 |
| 对白点 | 老陈（门外，感染后声音发闷）："小林，开门。我没咬人。" 林深（门内，冷静）："老陈，你上次说'我没咬人'，是第四天。第四天你咬了谁？" |

| 回收伏笔 | 无（开坑章） |

## 六、写作规范（紧张刺激专用）

- 全文中文，2000-2500字/章
- **紧张感三件套**（比《雾夜列车》更狠）：①每章至少1次"声音事件"（声=死）②每章至少1个倒计时（信标72小时充能）③每章末150字内必留钩
- 句式：短句为主，声音出现时句子变短（"门。撞了。"）
- 写实系：不写异能、不写系统、不写金手指面板。冷静=职业习惯（建筑工程师），不解释
- 章末钩子与上章不同式（第1章用第6式倒计时，第2章建议第11式"战斗中断"或第8式"新角色进场"）
