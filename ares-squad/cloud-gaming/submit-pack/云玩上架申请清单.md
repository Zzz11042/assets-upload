# 《阿瑞斯小队》TapTap 云玩上架申请清单

> 目标：申请 TapTap 云玩（cloud-gaming）能力，让游戏支持免下载即点即玩。
> 云玩上架 = 开发者后台授权申请 + 平台选品验收 + 提供全链路可验包体，非 CLI 可一键完成。

## 0. 关键事实
- 云玩由 TapTap 官方**选品**（非所有游戏都开通），需在开发者后台发起云玩授权申请后，平台全链路验收并适配最终上架（来源：TapTap 开发者文档「云玩功能介绍」第 7 节）。
- 移动端游戏走 **ARM 架构板卡方案**；PC/端游走 X86 VOS 容器方案。本游戏是 H5/WebGL，按 **Web 云玩**（默认使用安卓客户端包体）形态接入。

## 2. 云玩验收材料（提供给平台全链路测试）
1. **绿色免 launcher 包体**：纯 WebGL 网页构建，无安装器、无 launcher、无外部 http 依赖，单文件自包含 → 满足"绿色免 launcher"要求。
   - 路径：`taptap/ares-squad-h5.zip`（内 `game/index.html`）
2. **包体说明**：压缩 0.11 MB，远低于首包 60M 限制；单文件即可在任意现代浏览器运行。
3. **登录方式说明（云玩关键项，已核实）**：
   - 官方提示「云玩无法通过微信登录进入游戏」。
   - ✅ 本 H5 可玩版**无任何微信 / Tap SDK 登录引用**（源码检索：无 `open.weixin.qq.com` / `window.TAP` / `taplogin` 等），也**无服务端登录鉴权**。
   - 存档完全走 **浏览器本地 `localStorage`**（`localStorage.getItem/setItem`），属纯客户端离线存档。
   - 结论：**不存在「仅微信单一登录」的阻塞项**，云玩可直接进入、无需登录即可游玩，验收通过无登录障碍。若后续要接 Tap 云存档同步跨端，再单独评估。
4. **风控适配（已核实）**：
   - 源码中**无服务端固定 IP 校验 / 封禁 / 风控逻辑**（检索 `ipblock / blacklist / 封禁 / 风控 / anti-cheat / 外挂` 均无命中）。
   - 结论：云玩固定 IP 场景**无需做 IP 白名单或风控降权**，可直接验收。

## 3. 后台操作路径（需人工在 TapTap 开发者后台完成）
1. 进入 TapTap 开发者后台 → 对应应用（阿瑞斯小队 / 1005095）。
2. 找到「云玩 / 云游戏」授权入口 → 发起**云玩授权申请**。
3. 按平台选品流程填写：适配架构（Web/ARM）、提供免 launcher 包体、登录方式说明、风控说明。
4. 等待平台**全链路验收测试**（黑屏/白屏/闪退由开发者自测处理）。
5. 验收通过后平台最终上架云玩入口。

## 4. 信息核验结果（已补齐）
1. **登录方式**：无微信单一登录、无服务端登录鉴权；存档走浏览器 `localStorage`，纯客户端离线存档 → 无登录阻塞项。
2. **固定 IP 风控**：源码无服务端固定 IP 校验/封禁/风控逻辑 → 无需 IP 白名单或风控降权。
3. **验收材料打包**：见下方「§5 提交包」，可直接发给 TapTap 平台验收。
