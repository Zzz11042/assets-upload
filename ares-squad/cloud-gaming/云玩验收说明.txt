《阿瑞斯小队》TapTap 云玩验收说明
=====================================

一、包体形态
- 游戏类型：H5 / WebGL 网页构建（单文件自包含）
- 免 launcher：无安装器、无绿色 launcher、无外部 http 依赖
- 包体大小：压缩 117,426 B（约 0.11 MB），解压后 game/index.html 单文件 272,947 B
- 运行方式：任意现代浏览器 / TapTap Web 云玩容器直接打开 game/index.html 即玩，无需安装
- 首包体积远低于 60M 限制

二、登录方式（云玩关键项）
- 无微信登录、无服务端登录鉴权（源码无 open.weixin.qq.com / window.TAP / taplogin 等引用）
- 存档：纯客户端 localStorage 离线存档
- 结论：无「仅微信单一登录」阻塞项，云玩免登录即可游玩，验收无登录障碍

三、风控 / 固定 IP
- 源码无服务端固定 IP 校验、封禁、反作弊逻辑
- 结论：云玩固定 IP 场景无需 IP 白名单或风控降权，可直接验收

四、适配架构
- 按 Web 云玩形态接入（TapTap Web 云默认使用安卓客户端包体）
- 移动端游戏对应 ARM 板卡方案；本 H5 构建无 GPU 密集渲染，云设备性能要求低

五、验收前自测项
- 已确认：单文件可独立运行、无外部依赖、无崩溃风险项
- 黑屏/白屏/闪退：平台全链路验收测试后如有异常，由开发者按测试报告自测处理
