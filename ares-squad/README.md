# 末日小队 (Ares Squad) — H5 原型

玩法 = 小小部队(俯瞰即时小队战术) × 阿瑞斯病毒(末世生存经营+故事)。

## 可玩
`web/index.html` 单文件零依赖,浏览器直接打开(桌面/手机)。

## 结构
- 营地视图: 建筑(兵营/工坊/厨房/医疗站/围墙/电台)、小队、制作、生存管理、离线收益
- 任务视图: 3 士兵俯瞰即时战术,点取移动/攻击,手雷/火箭特殊技能,歼灭/护送/Boss 三种任务
- 存档: localStorage 单槽
