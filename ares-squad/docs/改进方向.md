## 改进方案（按优先级）

### ① 波次商店期 ⭐ 最高优先
**机制**：保卫/无尽模式，每波结束后暂停10秒，随机刷新3个商店项（武器强化/道具/建筑件），金币购买，本波有效。

**为什么**：Brotato节奏核心。当前保卫/无尽是"清完一波立刻下一波"，缺少消费点和决策节点。加10s商店期让节奏从"无限刷"变成"攒→消费→再刷"的循环。

**实现要点**：
- 波结束判定已有（`battleTotalSpawn >= m.totalSpawn`）
- 加 `battlePhase="shop"` 状态，暂停战斗10s
- 商店UI浮层（3个物品卡，随机刷新）
- 金币 = `S.gold`（战斗掉落）

### ② 武器协同词缀
**机制**：每件武器带1个标签（灼烧/暴击/穿透/电击/破甲），同标签≥3件时触发强化效果。

**为什么**：让玩家从"堆数值"转向"组deck"，增加构筑深度。当前武器只有数值升级，无协同。

**示例**：
- 灼烧×3 → 敌人持续减速15%
- 暴击×3 → 暴击伤害+50%
- 穿透×3 → 子弹穿透+1个目标

**实现要点**：武器定义加 `affix` 字段，战斗开始统计同类affix数，触发效果。

### ③ 精英怪（每5波）
**机制**：每第5波出现1只精英怪（体型大2倍，带光环buff：加速周围敌人/回复生命），击败额外掉落。

**为什么**：Rogue Tower的"敌人多解法"思路，增加视觉冲击和战术节点。

**实现要点**：`ENEMY_DEF` 加 `elite` 类型，波计数 `wave%5===0` 时刷出，光环用 `aura` 计时器。

### ④ 武器合成配方
**机制**：2件武器+2零件 → 解锁高阶武器（质变效果，非数值提升）。

**为什么**：VS超武合成是核心爽点。当前武器制作只有"数值升级"，无质变。

**示例**：
- 突击步枪+火箭筒+4零件 → 电磁步枪（穿透+灼烧双词缀）
- 冲锋枪+狙击+4零件 → 高斯步枪（超远射程+暴击）

**实现要点**：`WEAPONS` 加 `evoFrom` 字段，工坊加合成tab。

### ⑤ meta永久被动（战功系统）
**机制**：战斗结算给"战功"（基于击杀数/波数），战功在营地兑换永久被动。

**为什么**：VS哲学——meta解锁"选择"而非堆数值。当前成就只有金币奖励，无永久成长。

**示例被动**：
- 开局+10%移速
- 开局+5%血量
- 解锁新职业：工程师（带哨戒机枪）
- 开局多1发子弹

**实现要点**：`S.honor` 字段，营地加"战功兑换"tab，被动存 `S.permanent` 数组。

### ⑥ 每日挑战
**机制**：每日固定种子生成3层无尽挑战，排行榜钩子。

**为什么**：运营留存钩子，中短期可跳过。

## 推荐实施顺序

```
①波次商店 → ②协同词缀 → ③精英怪 → ④合成配方 → ⑤meta战功 → ⑥每日挑战
  (2h)        (1.5h)      (1h)       (2h)        (1.5h)     (4h+)
```
