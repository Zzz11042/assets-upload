# 墨剑江湖 V1 可玩 Demo（移动端优先）

> 定位：TapTap 上架的手机小游戏原型，竖屏体验，触屏操作为主，键盘为桌面备选。

## 快速开始
```bash
cd demo
# 手机直接打开（推荐）：起本地服务后手机同 WiFi 访问
python3 -m http.server 8901
# 手机浏览器打开 http://<电脑IP>:8901

# 桌面浏览器预览（自动居中竖屏容器）
open index.html        # macOS
xdg-open index.html    # Linux

# 跑全部验证（13/13 单测 + 无头 3600s 模拟 + 移动端 390x844 120 帧渲染桩）
node test.js
```

## 玩法（自动攻击版）
主角**自动攻击最近墨点/墨蛟**，你只需：
- 每波后点选残页（词缀 3 选 1）——核心肉鸽操作
- 满墨量时点「墨爆」/ 按 `空格` 释放全屏大招（破墨蛟护盾）
- `P` / `Esc` 暂停

无需按方向键，割草全自动。

## 移动端适配
- 竖屏优先：`100dvh` 全屏 + `env(safe-area-inset)` 刘海/手势条安全区
- 触屏控件常驻底部：上/右/下/左 4 方向 + 墨爆按钮（满墨量时呼吸发光提示）
- 词缀 3 选 1 手机单列卡片（带序号，点按即拾取，touchend 防双发）
- 横屏桌面浏览器时自动居中 430px 竖屏容器
- 游戏内右上角「Ⅱ」暂停按钮，切后台自动暂停
- 防双击缩放：`user-scalable=no` + `touch-action` 控制

## 水墨 UI 风格
- 宣纸底：多层 radial/linear 渐变 + 纤维纹理 + 晕染墨渍
- 标题/数字墨色渐变（浓墨→淡墨），朱砂「墨剑」落款印
- 面板宣纸卷轴：两侧墨边 + 内侧晕染 + 朱砂落款
- 词缀残页：微斜 + 内侧墨边 + 稀有度墨色浓度渐变
- 按钮墨印：浓墨底 + 朱砂描边 + 晕影
- 触屏按键：宣纸质 + 微墨边 + 朱砂墨爆

## 手感调优（解决"操控生硬"）
- 主角平滑转向：实际角度朝目标角度插值（消除瞬转）
- 挥击顿挫：笔剑按攻击节奏摆动（有节奏感）
- 挥击剑气弧光 + 待机剑锋高光
- 墨点敌人：存活时间调整（降低首波血量 + 持续刷怪），不再"一闪而过"

## 数值（方案 D 对齐）
- 每波 30s；怪物血 ×1.15^波；数量 ×1.04^波（同屏上限 90）
- 词缀 36 张，稀有度 60/25/10/4/1%，tier 桶 21/8/4/2/1
- 每级 +2% 基础属性（武学树）
- 墨蛟每 10 波 1 只，4 倍基础血，40% 护盾锁血，大招可破盾
- 大招：满墨量（100）后 CD 18s，清屏伤害 220×build.ult

## 防闪退
- `tick` 入口守卫：NaN/负/超大 dt 全部安全返回
- 每帧 rAF 回调 try/catch，单帧异常不冒泡
- 后台切页 `visibilitychange` 自动暂停
- 同屏墨点上限 90（防 OOM）
- 词缀池/墨渍/粒子全部带上限保护
- 渲染层所有 DOM 操作 try/catch 兜底
- `frame` 异常清屏兜底，保证画面不卡死
